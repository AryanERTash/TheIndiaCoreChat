# Quick Test Guide - Gemini Dynamic Content

## 🚀 Quick Start (2 Minutes)

### Step 1: Start Backend
```bash
python gemini_endpoint.py
```
**Expected:** Server starts on `http://localhost:8000`

### Step 2: Open Chatbot
```bash
# Option A: Direct file
open index.html

# Option B: Local server
python3 -m http.server 8080
# Then open: http://localhost:8080
```

### Step 3: Test Basic Flow
1. ✅ Select "English" from language dropdown
2. ✅ Click "Say Hi 👋" button
3. ✅ Wait for India description (generated by Gemini)
4. ✅ Verify state buttons appear in English
5. ✅ Click "Kerala" button
6. ✅ Wait for Kerala description (generated by Gemini)
7. ✅ Verify topic buttons appear in English
8. ✅ Click "Cuisine" button
9. ✅ Wait for Kerala cuisine info (generated by Gemini)

**Total Time:** ~30 seconds (depending on API speed)

## 🎯 What to Look For

### ✅ Success Indicators

1. **Dynamic Content**
   - Each response is unique (not from JSON)
   - Content is contextual and relevant
   - Responses are in selected language

2. **Button Consistency**
   - State buttons always in English
   - Topic buttons always in English
   - Buttons are clickable and functional

3. **Language Accuracy**
   - Bot responses match selected language
   - Proper script (Devanagari, Tamil, etc.)
   - Natural, fluent language

4. **Context Awareness**
   - Follow-up questions work
   - Bot remembers previous conversation
   - Relevant responses based on context

5. **Smooth UX**
   - Typing indicator shows during generation
   - Word-by-word animation works
   - Buttons appear after response

### ❌ Issues to Watch For

1. **Wrong Language**
   - Bot responds in English when Hindi selected
   - Mixed languages in response
   - **Fix:** Check system prompt includes language

2. **Buttons in Wrong Language**
   - State buttons translated
   - Topic buttons translated
   - **Fix:** Verify button creation uses English constants

3. **No Response**
   - Typing indicator stays forever
   - No error message
   - **Fix:** Check backend is running, check API key

4. **Generic Responses**
   - Response doesn't mention state/topic
   - Too vague or general
   - **Fix:** Improve prompt specificity

5. **Context Lost**
   - Follow-up questions don't work
   - Bot doesn't remember previous messages
   - **Fix:** Verify history is being sent

## 🔍 Debugging Tips

### Check Backend Logs

```bash
# Backend should show:
POST /chat - 200 OK
Processing request...
Response generated
```

### Check Browser Console

```javascript
// Should see:
Language changed to: hi
Sending API request...
Response received: {...}
```

### Common Issues

**Issue:** "Failed to fetch"
- **Cause:** Backend not running
- **Fix:** Start `python gemini_endpoint.py`

**Issue:** "Rate limit exceeded"
- **Cause:** Too many requests
- **Fix:** Wait 1 minute, try again

**Issue:** "API key invalid"
- **Cause:** Wrong or missing API key
- **Fix:** Check `.env` file has correct `GEMINI_API_KEY`

**Issue:** Response in wrong language
- **Cause:** System prompt not working
- **Fix:** Check `getSelectedLanguageName()` returns correct value
